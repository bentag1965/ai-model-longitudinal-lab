# Architecture Decision Records

Architecture Decision Records (ADRs) capture significant technical choices, the context behind them, and their consequences.

The purpose is not bureaucracy. It is to make design intent durable so future contributors can distinguish deliberate decisions from accidental implementation details.

## Format

Each ADR should include:

- Status
- Context
- Decision
- Consequences
- Alternatives considered
